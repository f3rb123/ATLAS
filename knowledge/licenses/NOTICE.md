GitHub Advisory Database: https://github.com/github/advisory-database — CC-BY-4.0. The copied license is GHSA.txt. Original advisory IDs/URLs, original raw bytes and conversion hashes remain attached to every canonical record. ATLAS normalization, chunking, redaction and semantic indexing are derivative processing; no source verification claim is changed into independent reproduction.

OWASP Cheat Sheet Series / Authorization Cheat Sheet: https://github.com/OWASP/CheatSheetSeries/blob/master/cheatsheets/Authorization_Cheat_Sheet.md — CC-BY-SA-4.0. The copied license is OWASP.txt. The normalized reference/chunks retain this license and original attribution. No endorsement by OWASP is implied.

CVE Program: https://github.com/CVEProject/cvelistV5 — use under https://www.cve.org/Legal/TermsOfUse. The official repository README explicitly permits search/download/use under those terms and is retained here. The terms page is a JavaScript application; a static fetch did not capture its full text, and no new blanket license is invented.

NVD/NIST: https://nvd.nist.gov/ and https://www.nist.gov/copyrights-disclaimers — NIST public-information distribution policy, except marked copyrighted material. The build's original policy review is recorded in BUILD_LOG. A later static refresh returned HTTP403; this notice is an attribution/reference, not a copied or invented license grant.

CISA KEV: https://github.com/cisagov/kev-data — CC0-1.0 per the official repository licensing section. Native feed bytes and the exact commit/acquisition URL are retained. Its official mirror supports alternate machine-readable access; the primary feed returned403 during this build.

OSV: https://osv.dev — upstream-dependent permissions. This build linked only five GHSA-origin OSV records to existing GitHub records under the upstream GHSA license. No unknown-upstream full-text permission is inferred.

Embedding model: sentence-transformers/all-MiniLM-L6-v2, ONNX distribution Qdrant/all-MiniLM-L6-v2-onnx at the pinned revision in embedding_model.json. Apache-2.0; standard license text is MODEL_APACHE.txt. The exact weight hash is verified against the pinned official Hugging Face LFS metadata. This distribution includes model weights, tokenizer and explicit checksums, not a generative model or provider key.

The corpus package contains these public records and derived vectors, with source-specific rights preserved. It contains no application master key, service credential, user/session database, private campaign or paid API credential. The application source's licensing is a separate owner decision; third-party data licenses do not license the entire application.
