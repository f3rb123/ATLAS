# Repository sandbox prerequisites
seccomp-bwrap.json derives from https://github.com/moby/profiles (Apache-2.0), default profile fetched during this build. It adds namespace/mount syscalls needed by Bubblewrap. Kernel user namespace capability checks remain in force. Containers stay non-root with all capabilities dropped, read-only roots and no-new-privileges. No privileged container or Docker socket is permitted.
Use compose.sandbox.yaml only on Linux hosts supporting unprivileged nested user namespaces. An AppArmor policy that denies user namespaces/mounts can still block this runner. Do not weaken the host's global policy; have the operator review a dedicated profile or use an approved isolated runner host. The doctor/benchmark must pass before enabling offline repository execution.
