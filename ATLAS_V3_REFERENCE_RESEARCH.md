## Additional primary-source study

- [PostgreSQL SELECT](https://github.com/postgres/postgres/blob/master/doc/src/sgml/ref/select.sgml), locking clause: SKIP LOCKED suits queue consumers, not a consistent database view. Use short claim transactions and fenced leases; never hold all run locks during model calls.
- [Redis Streams](https://github.com/redis/redis-doc/blob/master/docs/data-types/streams.md): consumer groups, XACK, XPENDING and XCLAIM support pending/recovery tracking. Notification delivery does not guarantee exactly-once execution. Keep SQL authoritative rather than add a second durable truth source now.
- [LangGraph checkpoint base](https://github.com/langchain-ai/langgraph/blob/main/libs/checkpoint/langgraph/checkpoint/base/__init__.py): thread/checkpoint IDs, channel versions, parent and pending-write metadata illustrate resumable state and per-task lineage. Adopt invariants, not a new framework dependency.
- [pgvector](https://github.com/pgvector/pgvector): cosine `<=>`, dimension-compatible vector indexes, approximate index recall/filter tradeoffs and hybrid-search patterns. Keep existing model version and dimensions. RRF/BM25/reranking require labelled evaluations; do not call current identity/cosine search BM25.
- [CloudEvents](https://github.com/cloudevents/spec/blob/main/cloudevents/spec.md): event source+id identity, type, subject, time and explicit schema/content type are useful for idempotency/provenance. A journal event is not itself task completion.
- [OWASP WSTG](https://github.com/OWASP/wstg/tree/master/document/4-Web_Application_Security_Testing): authoritative methodology taxonomy. Recommend selective versioned references over executable framework replacement.

Additional topics compared through those sources and the actual projects: context budgets, retrieval memory, model/provider independence, feedback review, independent verification, artifact lineage, per-agent concurrency, cancellation and restart, cost reservation and model retry ambiguity. No research benchmark or production efficacy experiment was run against these external projects.
